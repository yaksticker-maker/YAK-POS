YAK POS V4.4.47 - FRONT STOCK LOGIC FIX

แก้หน้าขายเมื่อสินค้าเชื่อมวัตถุดิบ:
- แถบแจ้งเตือนไม่ใช้สต๊อกสินค้า 0 สำหรับสินค้าที่เชื่อมวัตถุดิบ
- แสดงเตือนจากวัตถุดิบจริงเท่านั้น
- วัตถุดิบ A4 100 จุดเตือน 20 = ไม่เตือน
- ก่อนชำระเงิน ตรวจวัตถุดิบที่ต้องใช้จริง
- ถ้าวัตถุดิบพอ ให้ขายได้แม้ stock สินค้า = 0
- ถ้าวัตถุดิบไม่พอ จะแจ้งชื่อวัตถุดิบ + จำนวนที่ต้องใช้ + จำนวนที่เหลือ
- สินค้าที่ไม่ได้เชื่อมวัตถุดิบ ยังใช้ stock สินค้าตามเดิม
