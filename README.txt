V3.1 เพิ่มระบบตรวจสอบเครื่องพิมพ์บิลหน้าแรก
- เลือกกระดาษ 80 มม. หรือ 58 มม.
- ปุ่มทดสอบพิมพ์ใบเสร็จ
- บันทึกสถานะ พิมพ์สำเร็จ / พิมพ์ไม่ออก
- แสดงเวลาตรวจสอบล่าสุดที่หน้าแรก
- สถานะบันทึกแยกไว้ในเบราว์เซอร์เครื่องนั้น

ข้อจำกัด:
เว็บทั่วไปไม่สามารถอ่านชื่อ/ออนไลน์-ออฟไลน์ของเครื่องพิมพ์ระบบโดยตรงได้
จึงใช้การพิมพ์ทดสอบเพื่อยืนยันว่าเครื่องพิมพ์บิลพร้อมใช้งานจริง


V3.2 ระบบเงินสดและลิ้นชัก
- ช่องกรอกเงินสดที่ลูกค้าให้
- คำนวณเงินทอนอัตโนมัติ
- ปุ่มเงินด่วน 20 / 50 / 100 / 500 / 1000 / พอดี
- ตรวจเงินไม่พอก่อนปิดบิล
- บันทึกเงินรับและเงินทอนในข้อมูลบิล
- เปิดลิ้นชักอัตโนมัติหลังรับเงินสด
- ปุ่มเปิดลิ้นชักด้วยตนเอง

สำคัญเรื่องลิ้นชัก:
เว็บเบราว์เซอร์ทั่วไปไม่สามารถส่ง ESC/POS raw command โดยตรงได้
เวอร์ชันนี้จึงส่งงานพิมพ์ขนาดเล็กไปยังเครื่องพิมพ์บิล
หากเครื่องพิมพ์/ไดรเวอร์ตั้งค่า "Open cash drawer on print" ไว้
ลิ้นชักที่ต่อกับพอร์ต DK/RJ11 ของเครื่องพิมพ์จะเปิดอัตโนมัติ


V3.3
- ลิ้นชักเปิดได้เฉพาะเมื่อวิธีชำระ = เงินสด
- ปุ่มเปิดลิ้นชักถูกปิดอัตโนมัติเมื่อเลือก QR/โอน/บัตร
- หน้าขายมีสรุปยอดวันนี้แบบเรียลไทม์ตามสาขาที่ล็อกอิน
  * ยอดขายวันนี้
  * จำนวนบิลวันนี้
  * ยอดเงินสดวันนี้
  * ยอด QR/บัตรวันนี้
- หลังปิดบิลสำเร็จทุกครั้ง ระบบจะพิมพ์สลิปอัตโนมัติ
- สลิปแสดงเลขบิล วันที่ พนักงาน รายการ ยอดรวม ส่วนลด ยอดสุทธิ วิธีชำระ
- ถ้าเป็นเงินสด สลิปแสดงเงินรับและเงินทอน


V3.4 Touch Keypad
- เพิ่มแป้นตัวเลขขนาดใหญ่สำหรับหน้าจอสัมผัส
- ปุ่ม 0-9, 00, จุดทศนิยม
- ปุ่มลบทีละตัว
- ปุ่ม C ล้างยอดเงินสด
- ปุ่ม พอดี
- ปุ่ม ตกลง
- คำนวณเงินทอนทันทีทุกครั้งที่กดตัวเลข
- ยังคงปุ่มเงินด่วน 20 / 50 / 100 / 500 / 1000


V3.5 Daily Income Receipt Summary
- หน้าขายเพิ่มปุ่ม พิมพ์สรุปรายรับวันนี้
- เปิดหน้าตัวอย่างก่อนพิมพ์
- แสดงสาขา วันที่ เวลา ผู้พิมพ์ จำนวนบิล
- แสดงยอดเงินสด / QR-โอน / บัตร
- แสดงส่วนลดรวม รายรับรวม ต้นทุน และกำไรโดยประมาณ
- ต้องกดยืนยันการพิมพ์ก่อน จึงส่งไปเครื่องพิมพ์บิล


V3.6
- ปุ่มสรุปรายรับวันนี้ แสดงเฉพาะรายรับ ไม่แสดงต้นทุนหรือกำไร
- ยังคงแยก เงินสด / QR-โอน / บัตร / ส่วนลด / จำนวนบิล / รายรับรวม


V3.7.2 Persistent Printer
- เมื่อกดบันทึกเครื่องพิมพ์ ระบบจำชื่อเครื่อง วิธีเชื่อมต่อ กระดาษ และหมายเหตุไว้ถาวรในเครื่อง POS นี้
- เมื่อ Test Print ผ่านและกด พิมพ์สำเร็จ สถานะพร้อมใช้งานจริงจะถูกจำไว้
- ปิด Chrome / ปิดเครื่อง / เปิดระบบใหม่ ค่าที่บันทึกไว้จะถูกโหลดกลับอัตโนมัติ
- ข้อมูลจะยังอยู่ตราบใดที่ไม่ล้าง Site Data / LocalStorage ของเบราว์เซอร์


V3.8 Cash-only Hardware
- ลิ้นชักและเครื่องพิมพ์สลิปทำงานเมื่อกดชำระเงินและวิธีชำระเป็นเงินสดเท่านั้น
- QR / โอน / บัตร จะบันทึกการขายแต่ไม่เปิดลิ้นชักและไม่สั่งพิมพ์สลิป
- ตัดปุ่มเปิดลิ้นชักแบบ manual ออกจากหน้าขาย
- หลังเงินสดชำระสำเร็จ ระบบจะพิมพ์สลิปและส่งคำสั่งเปิดลิ้นชักทันที


V3.9 All Payment Receipt
- ทุกวิธีชำระเงินพิมพ์สลิปอัตโนมัติหลังปิดบิลสำเร็จ
- เงินสด: พิมพ์สลิป + เปิดลิ้นชัก
- QR / โอน / บัตร: พิมพ์สลิป แต่ไม่เปิดลิ้นชัก
