YAK POS V4.4.45 - FRONT / BACK SEPARATED

โครงสร้างใหม่ชัดเจน:
1) หน้าร้าน
- สำหรับพนักงานขาย
- กดหน้าร้าน -> Login พนักงาน
- ใช้รหัสพนักงาน + PIN
- Login สำเร็จ -> หน้าขาย POS โดยตรง
- ไม่แสดงระบบบริหาร

2) หลังร้าน
- สำหรับบริหารจัดการ
- กดหลังร้าน -> เข้าระบบบริหารโดยตรง
- ไม่มี PIN หลังร้าน
- เริ่มที่หน้า สินค้า / วัตถุดิบ
- มีสาขา พนักงาน สินค้า ยอดขาย รายงาน

ลบ front-entry standalone V4.4.44 ที่ทำให้โครงสร้างสับสนออกแล้ว
