YAK POS V4.4.18

หมวดหลังร้าน:
- สินค้า
- สต๊อก
- รายงาน
- พนักงาน / สาขา
- ตกแต่งสลิป
- ตั้งค่า

ตกแต่งสลิป:
- แยกเป็นหมวดของตัวเอง
- ใส่รูปหัวบิล / โลโก้ได้
- ลบรูปได้
- ชื่อร้าน/ข้อความ/เบอร์/QR/ท้ายบิลเดิมยังอยู่
- Preview ได้

สต๊อก:
- เพิ่มสินค้าได้ตลอด
- สินค้าที่ตัดสต๊อก เพิ่ม +1 / +10 / ลด -1 ได้
- กำหนดจำนวนคงเหลือเองได้
- เพิ่มวัตถุดิบหลักได้เอง เช่น A4, A3, สติ๊กเกอร์, หมึก
- กำหนดหน่วย จำนวนตั้งต้น และจุดเตือน
- เลือกวัตถุดิบแล้วติ๊กสินค้าที่จะเชื่อมได้หลายตัว
- กำหนดจำนวนวัตถุดิบที่ใช้ต่อการขาย 1 หน่วย
- แก้/ยกเลิกการเชื่อมเดิมได้
