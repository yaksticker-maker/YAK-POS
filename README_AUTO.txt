YAK POS V4.2 AUTO PAIR

ใช้งาน:
1. แตก ZIP
2. ดับเบิลคลิก YAK_POS_AUTO.bat
3. ครั้งแรก ถ้ายังไม่มี Electron ระบบจะติดตั้งให้อัตโนมัติ
4. โปรแกรมค้นหา Printer จาก Windows เอง
5. ถ้ามีเครื่องเดิมที่เคยบันทึก จะใช้เครื่องเดิมทันที
6. ถ้ามี Printer เพียงเครื่องเดียว จะจับคู่ให้อัตโนมัติ
7. ถ้ามีชื่อที่เข้าข่าย POS/Thermal/Receipt/XPrinter/EPSON TM ฯลฯ จะเลือกเครื่องนั้นให้อัตโนมัติ
8. หากมีหลายเครื่องและแยกไม่ได้ ให้เลือกเพียงครั้งเดียวแล้วกด ใช้เครื่องนี้ จากนั้นระบบจำตลอด

เงื่อนไขการขาย:
- เงินสด: พิมพ์สลิป + เปิดลิ้นชัก (เมื่อไดรเวอร์/เครื่องพิมพ์ตั้งเปิดลิ้นชักไว้)
- QR/โอน/บัตร: พิมพ์สลิป แต่ไม่เปิดลิ้นชัก

Windows ต้องติดตั้ง Driver เครื่องพิมพ์บิลให้เห็นใน Printers & scanners ก่อน
