YAK POS V4.4 SIMPLE PRINTER

หน้าเครื่องพิมพ์เหลือเพียง:
1. เลือก Printer จาก Windows
2. เลือก 58 หรือ 80 mm
3. กด ทดสอบ
4. กด บันทึก

หลังบันทึก ระบบจะจำ Printer ตัวเดิมให้อัตโนมัติทุกครั้งที่เปิดโปรแกรม
ไม่แสดง USB / Bluetooth / Unknown Device / Scale หรือค่าที่ไม่จำเป็น

ใช้งาน:
- เปิดผ่าน 'เปิด YAK POS.bat'
- Windows ต้องติดตั้ง Driver เครื่องพิมพ์ใบเสร็จไว้ก่อน
