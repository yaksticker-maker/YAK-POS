หน้า หลังร้าน > รายงาน > เลือกช่วงวันที่:
- ปุ่ม "บันทึก PDF"
- ปุ่ม "พิมพ์รายงาน"
- PDF เป็น A4
- เลือกตำแหน่งบันทึกไฟล์ได้
- Print เปิดหน้าต่างเลือกเครื่องพิมพ์ของ Windows
- รายงานพิมพ์ประกอบด้วย:
  ช่วงวันที่
  ยอดขายรวม
  จำนวนบิล
  รายจ่าย
  ต้นทุน
  กำไร
  ยอดเฉลี่ยต่อบิล
  เงินสด / QR-โอน / บัตร + %
  รายการสินค้า จำนวน และยอดขาย
  รายการรายจ่าย
