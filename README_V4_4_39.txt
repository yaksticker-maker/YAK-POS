YAK POS V4.4.39
เพิ่มการจัดการวัตถุดิบในอนาคต:
- ปุ่ม แก้ไข วัตถุดิบ
- แก้ชื่อ / หน่วย / จำนวนคงเหลือ / จุดเตือน
- ปุ่ม ลบ วัตถุดิบ
- ก่อนลบ ถ้าเชื่อมสินค้าอยู่ ระบบจะแสดงรายชื่อสินค้าที่เชื่อมและถามยืนยัน
- เมื่อลบ จะลบเฉพาะการเชื่อมที่เกี่ยวข้อง ไม่ลบสินค้าหลัก
- หลังแก้/ลบ รีเฟรชหน้าขายและหลังบ้านทันที
