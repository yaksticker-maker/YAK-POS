YAK POS V4.4.8 RAW RECEIPT + DRAWER FIX

แก้จาก V4.4.6 ของผู้ใช้โดยตรง

กฎ:
- เงินสด = พิมพ์สลิป RAW + เปิดลิ้นชัก
- QR / โอน = พิมพ์สลิป RAW เท่านั้น
- บัตร = พิมพ์สลิป RAW เท่านั้น

สิ่งที่เปลี่ยน:
- สลิปไม่พิมพ์ผ่าน Windows PrintDocument/Driver rendering แบบเดิม
- สลิปถูก Render เป็นภาพใน Chromium แล้วส่ง RAW ESC/POS Raster ไปที่ POS58
- ทำให้สลิปไม่มีคำสั่ง Cash Drawer ปะปน
- คำสั่งลิ้นชัก ESC/POS ถูกแยกเป็น IPC อีกชุด และเรียกเฉพาะเงินสด
- รองรับข้อความไทยเพราะสลิปถูก Render เป็นภาพก่อนส่ง
- ปุ่ม Test Print ก็ใช้ RAW Raster เช่นกัน และไม่สั่งลิ้นชัก

สำคัญ:
ถ้า QR/บัตรยังทำให้ลิ้นชักเด้งแม้ใช้ V4.4.8 นี้ แปลว่าเครื่อง/เฟิร์มแวร์หรือ Driver/Port ของ POS58
ถูกตั้งให้เด้งลิ้นชักเมื่อได้รับ RAW print job ซึ่งต้องแก้ที่ Printer Properties/Driver ของ POS58 โดยตรง
