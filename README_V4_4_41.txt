YAK POS V4.4.41
เพิ่มหน้าแสดงสถานะการทำงานของระบบวัตถุดิบทันทีเมื่อเปิดหน้า สินค้า:
- สินค้าอะไร → วัตถุดิบอะไร
- ใช้กี่หน่วยต่อขาย 1 หน่วย
- วัตถุดิบเหลือเท่าไร
- จุดเตือนเท่าไร
- สถานะ กำลังทำงาน / วัตถุดิบใกล้หมด / หยุดใช้งาน
- มีปุ่มแก้ไขและยกเลิกการเชื่อมจากรายการโดยตรง
- รีเฟรชอัตโนมัติหลังเพิ่ม/แก้/ลบ/เชื่อม
