หลังร้านแยกหน้า:
1. สินค้า
2. สต๊อก
3. รายงาน
4. พนักงาน / สาขา
5. ตั้งค่า

ระบบเชื่อมย้ายเข้า "สต๊อก" และทำใหม่ให้ง่าย:
ขั้น 1 เลือกวัตถุดิบ
ขั้น 2 ระบบแสดงสินค้าทั้งหมดให้เลือก/ติ๊กได้หลายตัว
ขั้น 3 ใส่จำนวนที่ใช้ต่อขาย 1 หน่วย
ขั้น 4 กดเชื่อม
ด้านล่างแสดงว่าเชื่อมกับอะไรอยู่ พร้อมแก้/ยกเลิก

ตัวอย่าง:
เลือก "กระดาษ A4"
-> เห็น ปริ้นสี / ปริ้นขาวดำ / ถ่ายเอกสาร / สินค้าอื่น
-> ติ๊ก ปริ้นสี + ปริ้นขาวดำ
-> ใส่ 1 แผ่น
-> กดเชื่อม

รายรับ/รายจ่าย/Today vs Yesterday อยู่หน้า "รายงาน"
ตกแต่งสลิป/เครื่องพิมพ์อยู่หน้า "ตั้งค่า"
วัตถุดิบ/การเชื่อม/เตือนของใกล้หมดอยู่หน้า "สต๊อก"
