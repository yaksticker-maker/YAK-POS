YAK POS V5.2 — OFFLINE SALE + AUTO/MANUAL CLOUD SYNC
====================================================

เพิ่มจาก V5.1:
1) เน็ตหลุดยังขายหน้าร้านต่อได้ โดยบิลถูกบันทึกใน Local Storage ของเครื่องทันที
2) ทุกบิลใหม่ถูกใส่คิว "บิลรอส่ง" ก่อน เพื่อกันบิลตกหล่น
3) เน็ตกลับมา ระบบลองส่งคิวขึ้น Cloud อัตโนมัติ
4) ระบบลองซ้ำทุก 15 วินาทีตราบใดที่ยังมีบิลค้างและมีอินเทอร์เน็ต
5) หน้าขายมีสถานะ Online / Offline / กำลัง Sync / มีข้อมูลค้าง
6) หน้าขายมีปุ่ม "เช็ก Cloud" และ "ส่งข้อมูลค้างตอนนี้" ให้พนักงานกดเองได้
7) แสดงจำนวนบิลรอส่งและเวลาที่ Sync สำเร็จล่าสุด
8) ตอน Sync จะอ่าน Cloud ล่าสุดก่อน แล้ว merge เฉพาะบิลที่ยังไม่มี เพื่อลดความเสี่ยงเขียนทับข้อมูลจากอีกเครื่อง
9) ถ้าบิลมีการตัดสินค้า/วัตถุดิบ ระบบจะตัดบน Cloud เมื่อ merge บิล Offline เข้า Cloud

คำแนะนำทดสอบ:
- เปิดระบบและให้ขึ้น Online
- ตัดอินเทอร์เน็ต
- ขายสินค้าทดสอบ 1 บิล
- ดูหน้าขาย: ต้องขึ้น Offline และ "บิลรอส่ง 1"
- ต่ออินเทอร์เน็ตกลับ
- รออัตโนมัติ หรือกด "ส่งข้อมูลค้างตอนนี้"
- เมื่อสำเร็จต้องเหลือ "บิลรอส่ง 0"

หมายเหตุ:
- ฟีเจอร์ V5.2 นี้เน้นรับประกันคิว "การขาย" ตอน Offline
- การแก้ไขข้อมูลหลังร้านจำนวนมากตอน Offline (เช่นแก้สินค้า/พนักงานพร้อมกันหลายเครื่อง) ยังไม่ใช่ระบบ conflict-resolution รายรายการ
