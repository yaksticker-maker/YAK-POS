YAK POS V4.4.23

ต่อจาก V4.4.22 Secure Back Office

ระบบวัตถุดิบ:
- เพิ่มวัตถุดิบเองได้
- เลือกสินค้า/บริการที่จะเชื่อมได้
- สินค้าหลายตัวเชื่อมวัตถุดิบเดียวกันได้
- สินค้า 1 ตัวเชื่อมหลายวัตถุดิบได้
- กำหนดจำนวนวัตถุดิบที่ใช้ต่อขายสินค้า 1 หน่วย
- เมื่อชำระเงินสำเร็จ ระบบรวมสูตรแล้วหัก:
  จำนวนขาย x จำนวนวัตถุดิบต่อหน่วย
- ก่อนหักจะตรวจว่าทุกวัตถุดิบพอ
- ถ้าวัตถุดิบไม่พอ จะไม่ปิดบิล
- ใส่สินค้าเข้าตะกร้าเฉย ๆ ไม่หักวัตถุดิบ

หลังร้าน > รายงาน:
- เลือก ตั้งแต่วันที่ -> ถึงวันที่
- ปุ่ม วันนี้ / เมื่อวาน / 7 วันล่าสุด / เดือนนี้ / เดือนที่แล้ว / ปีนี้
- ยอดขายรวม / จำนวนบิล / รายรับ / รายจ่าย / ต้นทุน / กำไร / เฉลี่ยต่อบิล
- เงินสด / QR-โอน / บัตร พร้อม %
- รายการสินค้า จำนวน และยอดขาย
- ปุ่ม บันทึก PDF
- ปุ่ม พิมพ์รายงาน
- ข้อมูลทั้งหมดอยู่หลัง PIN เท่านั้น

PIN / Security จาก V4.4.22 ยังเหมือนเดิม
