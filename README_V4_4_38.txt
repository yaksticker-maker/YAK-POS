YAK POS V4.4.38 - FRONT MATERIAL STOCK FIX

แก้หน้าขาย:
- ถ้าสินค้าเชื่อมวัตถุดิบแล้ว จะไม่ดูสต๊อกสินค้า 0 อีก
- ใช้สต๊อกวัตถุดิบเป็นตัวหลัก
- วัตถุดิบ > จุดเตือน = วัตถุดิบพร้อม
- วัตถุดิบ <= จุดเตือน = วัตถุดิบใกล้หมด
- วัตถุดิบ = 0 = วัตถุดิบหมด
- สินค้าแบบบริการที่ไม่ใช้สต๊อก แสดงเป็นบริการ
- ป้องกัน addToCart จากการบล็อกเพราะ stock สินค้า 0 เมื่อใช้วัตถุดิบ
